## Uso

Abra el PDF con cualquier lector compatible. No edite el PDF directamente; cualquier corrección debe hacerse sobre las fuentes LaTeX y luego recompilarse.

Para edición en Overleaf, suba el ZIP como proyecto nuevo, seleccione `manual_usuario.tex` como documento principal y use LuaLaTeX. No active `shell-escape`.
