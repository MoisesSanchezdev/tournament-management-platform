# Manifiesto de publicacion

El Manual Tecnico de la Plataforma Web Robot Explota Globos se declara publicado en version 1.0 el 2026-07-15.

## Declaraciones tecnicas

- La auditoria tecnica del proyecto fue utilizada como fuente base.
- La auditoria editorial fue ejecutada antes de la publicacion.
- Las observaciones documentales corregibles fueron cerradas.
- El manual fue compilado mediante LuaLaTeX y Biber.
- El PDF oficial fue generado desde la fuente LaTeX modular.
- El paquete Overleaf contiene los archivos fuente necesarios para edicion y recompilacion.
- No se modifico codigo funcional de la aplicacion para esta publicacion.
- No se incluyen archivos de entorno, credenciales reales, llaves privadas, tokens ni configuracion privada de produccion.
- Los nombres de variables de entorno aparecen solo como documentacion tecnica y no contienen valores secretos.

- Las rutas internas del paquete Overleaf usan separadores portatiles `/` y fueron verificadas entrada por entrada.
