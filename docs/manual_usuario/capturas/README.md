# Capturas del Manual de Usuario

Esta carpeta contiene el banco visual utilizado por el Manual de Usuario version 1.0.

## Estado actual

- `finales/`: 42 capturas PNG publicables, todas referenciadas por las fuentes LaTeX.
- `finales/metadata_capturas_finales.json`: trazabilidad del conjunto final.
- `base/`, `prueba/`, `revision/` y `descartadas/`: material intermedio local, excluido de Git.

## Politica de publicacion

Solo se versionan las capturas finales necesarias para compilar el manual. El material bruto y de revision puede regenerarse con las herramientas documentadas y no forma parte del entregable.

Todas las capturas deben:

- usar datos ficticios o anonimizados y una base temporal;
- omitir tokens, documentos, correos personales, telefonos y credenciales reales;
- respetar la numeracion y las convenciones visuales definidas en `planificacion/`.
