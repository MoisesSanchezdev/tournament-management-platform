\begin{advertencia}
Las rutas internas marcadas como organizador dependen de autenticacion y validacion de usuario staff o superusuario. Si se agregan roles mas granulares, esta matriz debe actualizarse junto con \cref{chap:seguridad}.
\end{advertencia}
